# 確認済みの修正とカタログ 8.0 の基準値の比較（BF16 の組、2026-10-07）

この報告は、同じ画像に完全版パイプラインを 2 回適用した結果を比べたものです。

- **B0（基準値）**: コミット 6c8c5d2（タスク一覧 8.0）。
- **B1**: B0 に、確認済みの修正 8 件だけを加えたもの。経路・起草・評価のそれ以外の部分は B0 と同じです。

どちらも BF16 の `Qwen/Qwen3.8-27B` と `google/gemma-4-31B-it` を使い、生成器 A のサーバーが画像のルーターを兼ねます。条件はどちらも同じで、3 GPU の分割配置、seed 20261004、英語、画像セットごとに 4 画像を同時に処理し、2 つの画像セットを同時に実行しました。

画像セットはどちらも評価専用です。

- **多様 269**: [`validation/diverse_269_20261007_manifest.json`](../../validation/diverse_269_20261007_manifest.json) の 269 画像。
- **P100**: 固定した Open Images V7 の検証用写真 100 枚。

「ゴールド」は GPT-6.1 Sol Ultra による評価で、人手の確認ではなく AI の参照評価です。確定したすべての往復で質問と回答がともに MET の会話を「ゴールド合格」と呼びます。

**B1 は、1 画像あたりの時間を除くすべての採否の基準を満たしました。** ゴールド合格の会話は、多様 269 で 28%、P100 で 35% 増えました。一方、多様 269 の 1 画像あたりの時間は B0 の 1.13 倍で、実行前に決めた上限の 1.1 倍を超えました。時間が増えたのは個々の処理が遅くなったからではなく、会話が先へ進むようになったためで、GPU 時間あたりのゴールド合格の会話は 15% 増えています。

## この修正だけにした理由

先に測った候補は、これらの修正に経路の変更を加えたものでした。構造化された操作を 1 往復目から提示し、検証器が棄権したときは 1 回だけ軽い検証の質問に切り替える、という変更です。その候補では、多様 269 のゴールド合格の会話が 47 から 31 に減り、時間も 1.8 倍かかりました。下の修正は、それぞれリプレイかゴールドの理由という別々の根拠を持っています。B1 では、経路の変更を除いてこれらだけを測りました。

| 修正 | 実行前の根拠 |
|---|---|
| 回答の解析を、許された結果 1 つに束縛する | 不正だった有限集合の解析が有効になった |
| 転写は、ダッシュ・引用符・空白を統一してから語と記号の列で比べる | 形式だけが違う不一致 5 件が合格になった |
| 数式・グラフ・有限集合の読み手が、出力の形式で失敗しないようにする | 不正な出力 |
| 判定者の理由を 25 語以内にし、再試行で不正な領域を名指しする | リプレイで判定者の出力の切断が 5 件から 0 件になった |
| 写っていない物は、確かに見える範囲でだけ問う | ゴールドが判定できない不在を 3 件不合格にした |
| 領域の Schema で、left と top を 1 未満、right と bottom を 0 より大きい値に限る | 領域の出力が失敗した 87 件で、有効な応答が 12 件から 60 件に増えた |
| 総合評価の判定者は、理由を判定より先に書く | 割れた判定者の組 211 組のうち、割れたままか不明の組が 175 から 93 に減った。不合格の回答の受理は増えなかった |
| JSON Lines は改行だけで分ける | U+2028 を含むモデルの文で、会話のファイルが読めなくなっていた |

## 変わったこと

- **判定者の割れが減った。** 判定者の割れで止まった会話は、多様 269 で 73 から 32 に、P100 で 27 から 13 に減りました。その分、多くの往復が後の段階まで進みました。多様 269 の確定した往復は 262 から 335 に増えましたが、モデル呼び出しの増加は 3,857 から 4,289 にとどまりました。確定した 1 往復あたりの呼び出しは 14.7 から 12.8 に、ゴールド合格 1 会話あたりの時間は 161 秒から 143 秒に減っています。
- **検証器の棄権が増えた。** 検証器まで届くようになった往復は、そこで止まることも増えました。2 人の判定者が受け入れたのに検証器が UNKNOWN になった停止は、多様 269 で 23 から 33 に増えました。多くは数え上げの操作の閉集合の検査で、その読み手はまだ内容より先に coverage を求める項目順です。
- **判定できない不在が残った。** 写っていない物を問う質問は、隠れた・ぼけた・画面外へ切れた範囲で、なおゴールドに不合格とされました。P100 で確定した `object_presence` 9 往復のうち 7 往復が不合格です。起草と判定者に与えた「見える範囲で問う」規則は、参照評価の水準に届いていません。
