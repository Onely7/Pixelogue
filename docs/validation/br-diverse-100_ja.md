# 多様な 100 評価画像での完全版パイプライン（BF16 の組、2026-10-07）

この報告は、現在のパイプラインを [`validation/diverse_100_20261004_manifest.json`](../../validation/diverse_100_20261004_manifest.json) の 100 画像に適用した 1 回の実行の記録です。モデルは BF16 の `Qwen/Qwen3.8-27B` と `google/gemma-4-31B-it` で、生成器 A のサーバーが画像のルーターを兼ねます。実行は、下で説明する起草の形式の修正の後に行いました。画像は 10 層に分かれた、評価専用の Wikimedia Commons ファイルです。「ゴールド」は GPT-6.1 Sol Ultra による評価で、人手の確認ではなく AI の参照評価です。

## Gemma 4 の質問案の失敗

修正前は、BF16 の 4 run で Gemma の起草呼び出しの 43.8% が Schema 検証に失敗していました。起草の失敗全体の 72% は、面積のない領域や逆転した領域です。

領域の上限を 1000 に広げて送ると、Gemma は 440 個の領域のうち 437 個を 100 を超える値で書きました。Gemma は自分に馴染みのある 0〜1000 の尺度で座標を書き、それが構造化出力の制約で `{1, 1, 1, 1}` の領域や空白の暴走に切り詰められていました。

修正後の起草の指示では、次の 2 点を明記しています。再試行の説明でも、この 2 つの形式を伝えます。

- 領域は 0〜1 の割合で、left < right、top < bottom。
- `public_parameters` は名前と値の組の配列。

| 同じ起草要求（Gemma 160 件、Qwen 80 件） | Gemma の受理 | Qwen の受理 |
|---|---|---|
| 修正前の指示 | 88（55.0%） | 47（58.8%） |
| 形式を明記（採用） | 136（85.0%） | 55（68.8%） |

Gemma の差は McNemar の p < 0.0001 です。下の実行では、Gemma の起草の Schema 不適合は 110 回中 3 回（2.7%）でした。

## 実行の条件と結果

- 設定は standard プロファイルのまま、`configs/split-pilot.yaml` の 3 GPU の分割配置を使いました。
- seed は 20261004、言語は英語で、準備済みデータセットごとに 4 画像を同時に処理しました。
- 2 つの準備済みデータセット（60 枚と 40 枚）は同時に実行しました。

| 項目 | 結果 |
|---|---|
| 所要時間 | 100 画像で 31.7 分（189 画像/時、8 画像同時） |
| 合成の GPU 時間 | 1.58 GPU 時間（3 枚） |
| モデル呼び出し | 1,518 回、入力 424 万トークン、出力 19 万トークン |
| エラー | 0 |
| 品質候補 | 38 会話、確定往復 83 |
| 選抜後 | 35（1 画像・1 視覚グループに 1 会話、同じ意味系統の重複なし）。出力は評価画像を拒否 |
| ゴールドで全往復 MET の会話 | 38 中 22（58%）。往復単位では 83 中 64 で、質問・回答とも MET |

モデルの稼働時間の内訳は、起草 37%、質問ゲート 25%、総合評価 14% です。

## どこで往復が失われるか

試行した 185 往復のうち 105 往復が確定しました。失敗した 80 往復の内訳は次のとおりです。

- 65 往復は回答の総合評価で失敗しました（不合格 31、判定保留 34）。
- 7 往復は、有限集合の答えを読み取る段階で、Qwen が宣言した答えの値を省いて失敗しました。デコーダーでは強制できない Schema の問題です。
- 残りは、質問ゲートで停止 3、通る案がない 2、回答の生成の失敗 2、反復停止 1 です。

## 多様性

| 観点 | 結果 |
|---|---|
| 操作 | 72 種中 20 種。偏りは小さい（正規化エントロピー 0.93） |
| 系統 | 14 種中 9 種。ただし視覚的な記述、参照と空間、文字の読み取りで往復の 90% |
| 必要な能力 | 50 種中 20 種 |
| 質問文 | 83 件中 82 件が異なる |
| 会話の往復数 | 2 往復 33、3 往復 4、5 往復 1 |

往復数の多様性はまだ確保できていません。3 往復目以降はたいてい回答の総合評価か有限集合の答えの読み取りで止まり、会話は受理済みの 2 往復に切り詰められます。表・グラフ・図・数式のような構造化された層は、ほとんど残りません。
